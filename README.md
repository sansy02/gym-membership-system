# Gym Membership System

Java OOP coursework project with two versions.

## GymMembershipSystem (Swing GUI)

Desktop application built with Java Swing + MySQL (JDBC).

- OOP concepts: encapsulation, abstraction, multi-level inheritance, polymorphism, interface (IPayable), aggregation, dependency
- Setup: import `sql/setup.sql` into MySQL (XAMPP), then run `compile.bat` and `run.bat`
- Default logins: `admin / admin123` (Receptionist), `trainer1 / 123456` (Trainer)

## GymWebSystem (Web)

Browser-based version: pure-Java HTTP server + HTML/CSS/JS frontend.

- Setup: start XAMPP MySQL, import `sql/setup.sql`, run `compile.bat`, then `run.bat`, open http://localhost:8080
